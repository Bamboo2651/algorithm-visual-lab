# アルゴリズム可視化ラボ

PythonとPygameで、アルゴリズムの途中経過と処理速度を可視化する学習用アプリです。

## 収録アルゴリズム

### ソート

- バブルソート
- 挿入ソート
- 選択ソート
- カクテルソート
- シェルソート
- マージソート
- クイックソート
- ヒープソート
- 計数ソート

### 素数探索

- 試し割り法
- エラトステネスのふるい

### 数列

- レカマン数列
- コラッツ数列

## 環境構築

このプロジェクトはPython 3.14と、Python 3.14に対応している `pygame-ce` を使用します。

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### `python -m pip` を使う理由

パッケージは次のように直接インストールすることもできます。

```powershell
pip install flask
```

このプロジェクトでは次の形式を使用します。

```powershell
python -m pip install -r requirements.txt
```

- `python -m pip` は、現在選択しているPython環境のpipを実行する
- `-r requirements.txt` は、ファイルに記録されたパッケージをまとめて導入する
- 別のPythonへ誤ってインストールする事故を減らせる
- 別のPCでも必要なパッケージを再現できる

インストールする名前は `pygame-ce` ですが、プログラムでは通常どおり `import pygame` と書きます。

## 起動方法

```powershell
.\.venv\Scripts\Activate.ps1
python app.py
```

## 操作方法

- マウス: モードやアルゴリズムを選択
- `個別表示`: 1種類のアルゴリズムを大きなグラフで観察
- `全体比較`: カテゴリ内の全アルゴリズムを同じ条件で同時実行
- `スタート`: アルゴリズムの実行と時間計測を開始
- `1` / `2` / `3`: ソート、素数探索、数列へ移動
- `Space`: 一時停止・再開
- `→`: 1ステップ進める
- `R`: 現在のアルゴリズムをリセット
- `Esc`: ホームへ戻る
- `データ量`: 比較に使用する要素数、探索上限、生成ステップ数を変更
- `表示速度`: 1秒間に画面上で進めるステップ数を変更

全体比較では、各カードにアルゴリズム名、実行状態、処理回数、1秒あたりの処理回数を表示します。ソートでは全種類に同じ初期配列を渡すため、動きや処理量の違いを比較できます。

モードを開いた直後とリセット直後は「開始待ち」です。スタートを押すまではアニメーションは進みません。完了したアルゴリズムには、ベンチマークで測定した処理回数と完了時間が表示されます。

## 計算時間と表示速度

表示速度は、アニメーションを見やすくするための設定です。変更してもアルゴリズムの計算時間には含まれません。

スタート時に、画面描画を行わない計測専用のアルゴリズムを最後まで実行します。`time.perf_counter()` で6回測定し、最初のウォームアップを除いた5回の中央値を採用します。毎秒処理数も、このベンチマーク時間を基準に計算します。

計測後、画面上のアルゴリズムは固定済みの測定結果を変えずにアニメーションします。同じデータ量の結果はアプリ内へキャッシュされるため、表示速度を変更してリセットしても、完了時間と処理回数は同じです。

データ量はカテゴリごとに次の意味を持ちます。

- ソート: 並び替える数値の個数
- 素数探索: 2から探索する上限値
- 数列: 生成する最大ステップ数

データ量を変更すると、現在のカテゴリは新しい条件で開始待ちへ戻ります。全体比較では、すべてのアルゴリズムに同じデータ量を使用します。

ソートの入力配列はデータ量から決まる固定シードで生成します。同じデータ量ならリセット後も同じ並びになり、再測定の条件が変わりません。

## ファイル構成

```text
app.py                      GUIとユーザー操作
algorithms/
  sorting/                  ソート（1アルゴリズム1ファイル）
  primes/                   素数探索
  sequences/                数列
tests/                      アルゴリズムの自動テスト
```

アルゴリズム本体とPygameの描画処理を分離しています。アルゴリズムを復習するときは、`algorithms/` 内の対象ファイルだけを読めます。

## テスト

```powershell
python -m pytest -q
```

すべてのソート結果、素数一覧、数列の代表値を自動確認します。
