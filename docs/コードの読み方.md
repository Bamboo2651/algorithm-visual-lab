# アルゴリズムコードの読み方

## 最初に読むファイル

初めて読む場合は、次の順番がおすすめです。

1. `algorithms/sorting/bubble.py`
2. `algorithms/sorting/insertion.py`
3. `algorithms/sorting/selection.py`
4. `algorithms/sorting/merge.py`
5. `algorithms/sorting/quick.py`
6. `algorithms/sorting/heap.py`

最初の3つは基本的な繰り返し処理で書かれています。マージソート以降では、関数が自分自身を呼ぶ「再帰」が登場します。

## `state` とは

各アルゴリズムは、途中状態を `state` に保存します。

```python
state.values
state.active_indices
state.comparisons
state.writes
state.message
```

- `values`: 並び替え中の数列
- `active_indices`: 現在比較している位置
- `comparisons`: 比較した回数
- `writes`: 値を書き換えた回数
- `message`: GUIへ表示する現在の操作

アルゴリズムは計算だけを担当し、`app.py` は `state` を読み取って描画します。

## `yield` とは

通常の関数は、`return` するまで一気に実行されます。可視化では一気に実行すると途中経過が見えません。

```python
state.comparisons += 1
yield
```

`yield` に到達すると、その場所で処理が一時停止します。GUIが画面を1回描いた後、次のステップで続きから再開します。

このような関数を「ジェネレーター」と呼びます。

## `dataclass` とは

`common.py` では、関連する変数をまとめるために `dataclass` を使用しています。

```python
@dataclass
class SortState:
    values: list[int]
    comparisons: int = 0
```

これは、次のようにデータをまとめて扱うためのクラスです。

```python
state = SortState(values=[3, 1, 2])
state.comparisons += 1
```

## 計算量の見方

`n` は、処理するデータ数を表します。

- `O(n)`: データが2倍になると、処理量もおよそ2倍
- `O(n²)`: データが2倍になると、処理量はおよそ4倍
- `O(n log n)`: `O(n²)` より増え方が緩やか
- `O(1)`: データ数が増えても必要量がほぼ一定

画面の「処理回数」と「毎秒処理」を見ながら、数列の長さを変えたときの違いを確かめられます。

## 新しいアルゴリズムを追加する流れ

1. 対応するフォルダーへ新しいPythonファイルを作る
2. `create_steps()` を書く
3. 比較や書き込みの直後へ `yield` を置く
4. `ALGORITHM` に名前、説明、計算量を登録する
5. フォルダーの `__init__.py` へ追加する
6. `python -m pytest -q` で結果を確認する

この構成により、GUIを大きく変更せずにアルゴリズムを増やせます。
